# Repository scope

The public repository is deliberately kept small.

## Included

- Authored C++, Python and UnrealScript source code.
- Selected small CSV/TSV/TXT/JSON manifests needed to understand mappings.
- Character-specific audio QA and preparation tools.
- Runtime audio/subtitle experiments and validation reports.

## Excluded

- WAV, MP3, OGG and other generated voice files.
- Original or modified game packages and executables.
- DLLs, Unreal packages, FMVs and extracted game assets.
- Build directories, staging areas and backups.
- Wine prefixes and Python virtual environments.
- AI model weights and caches.
- Large generated QA plots and temporary logs.
- Large integration datasets that are not required to understand the source.

The local development project remains the authoritative working copy. This
repository is a curated technical source mirror rather than a full workspace
backup.
